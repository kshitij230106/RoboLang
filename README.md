# 🤖 RoboLang — Robot Programming Language & 2D Simulator

**RoboLang** is a custom programming language designed for controlling a virtual robot in a **2D simulation environment**.

The project demonstrates the major stages of a compiler pipeline, starting from **lexical analysis and parsing** and progressing through **AST construction, semantic analysis, intermediate representation, code generation, and virtual machine execution**.

The project also includes a **web-based robot simulator** that visually represents the robot's movement based on RoboLang programs.

---

## 🎯 Project Overview

RoboLang allows users to write simple robot-control programs such as:

```text
MOVE 100
TURN RIGHT
MOVE 50
TURN LEFT
MOVE 30
```

The RoboLang compiler processes this program through multiple stages:

# ✨ Features

## 🔤 Custom Programming Language

RoboLang provides commands specifically designed for robot control.

Example:

```text
MOVE 100
TURN RIGHT
MOVE 50
TURN LEFT
MOVE 30
```

---

## 🔍 Lexical Analysis

The lexer converts the source program into a sequence of tokens.

For example:

```text
MOVE 100
```

can be converted into tokens representing:

```text
MOVE
NUMBER(100)
```

The lexer identifies keywords, numbers, commands, and other language elements.

---

## 🌳 Abstract Syntax Tree

The parser constructs an **Abstract Syntax Tree (AST)** from the source program.

Example AST:

```text
Program
├── MoveCommand(100)
├── TurnCommand(RIGHT)
├── MoveCommand(50)
├── TurnCommand(LEFT)
└── MoveCommand(30)
```

Current AST structures include:

```python
Program
MoveCommand
TurnCommand
```

---

## 🧠 Semantic Analysis

The semantic-analysis stage validates the meaning of the parsed program.

Examples of checks can include:

* Valid robot commands
* Valid movement distances
* Valid turn directions
* Invalid command combinations
* Invalid values

This prevents syntactically valid but semantically invalid programs from reaching execution.

---

## ⚙️ Intermediate Representation

After semantic analysis, the program is converted into an intermediate representation suitable for execution.

Example:

```text
MOVE 100
TURN RIGHT
MOVE 50
TURN LEFT
MOVE 30
```

can be represented internally as a sequence of instructions such as:

```text
OP_MOVE 100
OP_TURN RIGHT
OP_MOVE 50
OP_TURN LEFT
OP_MOVE 30
```

---

## 💻 Bytecode Generation

RoboLang generates bytecode instructions that can be executed by the virtual machine.

Example:

```text
Bytecode:
OP_MOVE 100
OP_TURN RIGHT
OP_MOVE 50
OP_TURN LEFT
OP_MOVE 30
```

---

# 🖥️ Virtual Machine

The RoboLang Virtual Machine executes the generated bytecode.

The VM maintains the robot's:

* Position
* Direction
* Movement
* Path

Example execution:

```text
Virtual Machine Execution

Initial Position: (0, 0)

MOVE 100
TURN RIGHT
MOVE 50
TURN LEFT
MOVE 30

Final Robot State:
Position: (50, 130)
Direction: NORTH
```

The VM acts as the execution engine for RoboLang programs.

---

Instead of using a desktop graphics library, RoboLang uses a **web-based simulator**.

The simulator provides a visual representation of the robot and its movement.


# 🚀 Getting Started

## Prerequisites

Install:

* Python 3.10+
* pip

Check Python:

```bash
python --version
```

---

## 📥 Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/RoboLang.git
```

Move into the project:

```bash
cd RoboLang
```

---

## 📦 Install Dependencies

```bash
pip install -r requirements.txt
```

If a requirements file is not available:

```bash
pip install fastapi uvicorn
```

---

# ▶️ Running the Compiler

The compiler components can be executed individually.

### Run the Parser

```bash
python -m compiler.parser
```

Example output:

```text
Program(
    statements=[
        MoveCommand(distance=100),
        TurnCommand(direction=RIGHT),
        MoveCommand(distance=50),
        TurnCommand(direction=LEFT),
        MoveCommand(distance=30)
    ]
)
```

---

### Run the Virtual Machine

```bash
python -m compiler.vm
```

The VM executes the generated instructions and displays the final robot state.

Example:

```text
Lexical Analysis
Syntax Analysis
Semantic Analysis
IR Generation
Code Generation

Bytecode:
...

Virtual Machine Execution

Final Robot State:
Position: (50, 130)
Direction: NORTH
```

# 🌐 Running the Web Backend

Start the FastAPI server:

```bash
uvicorn backend.main:app --reload
```

The backend provides endpoints for interacting with the robot simulator.

Example:

```text
GET /
```

Returns:

```text
RoboLang Backend running
```

Robot state:

```text
GET /robot
```

Program execution:

```text
POST /execute
```

# 💡 Why RoboLang?

Traditional compiler projects often stop after generating intermediate code or demonstrating parsing.

RoboLang extends the compiler pipeline into an **interactive visual execution environment**.

```text
Compiler Theory
      +
Programming Language
      +
Virtual Machine
      +
2D Simulation
      =
RoboLang
```

This makes it possible to visually observe the effect of compiled instructions on a virtual robot.
